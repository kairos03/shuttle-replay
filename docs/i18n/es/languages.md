# Idiomas

Este sitio de documentación se publica en diez idiomas. Cada página tiene en
la parte superior un selector de idioma que abre la misma página en otro
idioma.

<!-- docs-language-links -->

El código fuente, los mensajes de la CLI, los nombres de campos JSON y el
texto oficial de la licencia están en inglés en todas las versiones de idioma.

El README del proyecto también está traducido; consulta los enlaces de idioma
en la parte superior de
[README.md](https://github.com/KAIROS03/shuttle-replay/blob/main/README.md) en
GitHub.

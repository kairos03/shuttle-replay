# Lingue

Questo sito di documentazione è pubblicato in dieci lingue. Ogni pagina ha in
alto un selettore di lingua che apre la stessa pagina in un'altra lingua.

<!-- docs-language-links -->

Il codice sorgente, i messaggi della CLI, i nomi dei campi JSON e il testo
ufficiale della licenza sono in inglese in tutte le versioni linguistiche.

Anche il README del progetto è tradotto; vedi i link alle lingue in cima a
[README.md](https://github.com/KAIROS03/shuttle-replay/blob/main/README.md) su
GitHub.

# Langues

Ce site de documentation est publié en dix langues. Chaque page comporte en
haut un sélecteur de langue qui ouvre la même page dans une autre langue.

<!-- docs-language-links -->

Le code source, les messages de la CLI, les noms de champs JSON et le texte
officiel de la licence sont en anglais dans toutes les versions linguistiques.

Le README du projet est également traduit ; voir les liens de langue en haut
de [README.md](https://github.com/KAIROS03/shuttle-replay/blob/main/README.md)
sur GitHub.

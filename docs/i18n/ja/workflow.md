# ワークフロー

## 用意するもの

- **検出結果**（`tracks.json`）：デコードされたフレームごとに 1 エントリで、PTS、カメラセグメント id、シャトルのピクセルまたは null、任意の選手ボックスを含みます。検出器は内蔵されていません。[](schemas.md) を参照してください。
- **キャリブレーション入力**：セグメントごとに、少なくとも 4 つの `fit` コート点、いくつかの `heldout` 点、両方のネットポストの上端（1.55 m）。
- **レビュー**（`review.json`）：あなたがレビューした打点時刻、ピクセル、高さと、任意の着地領域。打点は自動では検出されません。

検出結果はどのトラッカーで作成してもかまいません。たとえば、自分のチェックポイントを使ってシャトルには TrackNetV3 (MIT)、選手には Ultralytics YOLO モデル (AGPL-3.0) を自分で実行し、その出力を変換できます。変換スクリプトは v0.1 には含まれていません。

## 手順

1. **キャリブレーション。** カメラセグメントごとに、≥ 4 点のコートラインの交点（ロール `fit`）、さらに `heldout` 用にいくつか、そして 2 本のネットポストの上端を計測します。

   ```bash
   uv run shuttle-replay calibrate calibration_input.json -o calibration.json
   ```

   先に進む前に `heldout_summary` と `net_anchor_sensitivity` を確認してください。
2. **レビュー。** `review.json` を書きます。レビュー済みの区間内の打点時刻、打点のピクセルと高さの事前分布、そしてセグメントの最後の飛行については任意の着地領域または `open` を記述します。
3. **解析とレンダリング。**

   ```bash
   uv run shuttle-replay analyze --tracks tracks.json --review review.json \
       --calibration calibration.json -o analysis.json
   uv run shuttle-replay render --video match.mp4 --analysis analysis.json -o replay.mp4
   # or both at once:
   uv run shuttle-replay run --video match.mp4 --tracks tracks.json --review review.json \
       --calibration calibration.json --out-dir out
   ```

   矛盾した入力（単調でない PTS、連続していないセグメント、セグメントや区間の外にある打点、動画と一致しない PTS など）は、メッセージとともに終了コード 2 で停止します。黙って修復されるものはありません。

## 各コマンドの役割

- **`calibrate`**：レビュー済みの ≥ 4 点の床面点からホモグラフィを求め、さらに ≥ 2 点の床から離れたネットアンカーからカメラ行列の鉛直列を求めます。ホールドアウトの床面点はフィッティングに決して使われず、別途報告されます。退化した入力、重複した入力、同一直線上の入力、有限でない入力は拒否されます。床面ホモグラフィが空中の点に使われることはありません。
- **`analyze`**：レビュー済みの打点ごとに 1 つの飛行を作り、レビューした打点から時間を計ります。カメラの切り替えは除外され、飛行がセグメントをまたぐことはありません。各飛行は、次の打点、レビュー済みの着地領域（実測座標ではなく制約）、またはセグメントの最後の観測で終わります。床面とネットのゲートが実現不可能なフィットを拒否します。欠落した検出は null のままです。
- **`render`**：デコードしたすべての元フレームをトラックの PTS と照合し、与えられた選手ボックス、観測されたシャトルの円（緑）、モデルの円（オレンジ）、俯瞰コート図を 6:4 のレイアウトで描画します。元の音声は再エンコードせずにストリームコピーされます。既存の出力が上書きされることはありません。
- **`demo`**：合成ラリーを生成し、パイプライン全体を実行します。

## 出力の読み方

| レイヤー | 意味 |
| --- | --- |
| `observed_pixel` | 与えられた検出結果をそのまま。存在しない場合は null |
| `human_review` | あなたの打点、着地領域、キャリブレーション点 |
| `conditional_model` | あなたの事前情報の下で観測ピクセルにフィッティングした物理モデル |
| `display_interpolation` | レンダラーが描くだけの線とマーカー |

速度はフィッティングしたモデルの初速です（`model_speed_km_h`、5 km/h 単位に丸めて表示）。測定値ではなく、おおまかなモデル値として扱ってください。

## 制限事項

- シャトルや選手の検出はなく、重みも同梱されていません。
- 打点の自動検出や打点タイムスタンプの補正はありません。
- 学習済みの密な深度マップ、学習済みのショットラベル、自動の IN/OUT 判定はありません。
- 3D 出力は条件付きであり、実測ではありません。合成データでの復元結果はあくまで合成データでの結果です。

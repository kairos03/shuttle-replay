# shuttle-replay

```{image} assets/header.svg
:alt: shuttle-replay
:width: 100%
```

**ローカルのバドミントン動画、あなたの検出結果、あなたのレビューを、左右に並べたコートリプレイに変換します。オフラインで動作します。**

`shuttle-replay` は、あなたがレビューしたコート上の点からカメラをキャリブレーションし、あなたが用意した 2D シャトル検出結果に重力と二次空気抵抗を含む飛行モデルをフィッティングし、元動画と俯瞰コート図を並べた MP4 をレンダリングします。

これは研究とレビューのためのツールであり、ライン判定システム、ショット分類器、シャトル検出器、実測の 3D スピードガンではありません。

- **検出結果はあなたが用意します。** シャトルや選手の検出器は同梱されておらず、モデルの重みもダウンロードされません。
- **レビューはあなたが行います。** 打点、着地領域、キャリブレーション点は人がレビューします。何かが自動で検出されたり修正されたりすることはありません。
- **3D は条件付きであり、実測ではありません。** すべての 3D 位置と速度は、あなたのキャリブレーションとアノテーションに依存する物理モデルの出力です。学習済みの深度推定はなく、再投影誤差が小さいことは 3D 精度の証明にはなりません。

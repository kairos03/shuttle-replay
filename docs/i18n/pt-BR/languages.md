# Idiomas

Este site de documentação é publicado em dez idiomas. Cada página tem no topo
um seletor de idioma que abre a mesma página em outro idioma.

<!-- docs-language-links -->

O código-fonte, as mensagens da CLI, os nomes de campos JSON e o texto oficial
da licença estão em inglês em todas as versões de idioma.

O README do projeto também é traduzido; veja os links de idioma no topo do
[README.md](https://github.com/KAIROS03/shuttle-replay/blob/main/README.md) no
GitHub.

# Рабочий процесс

## Что вы предоставляете

- **Детекции** (`tracks.json`): одна запись на каждый декодированный кадр с
  PTS, id сегмента камеры, пикселем волана или null и необязательными рамками
  игроков. Встроенного детектора нет. См. [](schemas.md).
- **Входные данные калибровки**: для каждого сегмента не менее 4 точек корта
  `fit`, несколько точек `heldout` и обе верхушки стоек сетки (1.55 м).
- **Проверка** (`review.json`): проверенные вами времена касаний, пиксели и
  высоты, а также необязательные зоны приземления. Касания не находятся
  автоматически.

Детекции может создать любой трекер; например, вы можете сами запустить
TrackNetV3 (MIT) для волана и модель Ultralytics YOLO (AGPL-3.0) для игроков
со своими чекпойнтами и преобразовать их выходные данные. Скрипты
преобразования не входят в v0.1.

## Шаги

1. **Калибровка.** Для каждого сегмента камеры измерьте ≥ 4 пересечения линий
   корта (роль `fit`), ещё несколько как `heldout` и две верхушки стоек сетки.

   ```bash
   uv run shuttle-replay calibrate calibration_input.json -o calibration.json
   ```

   Прежде чем двигаться дальше, проверьте `heldout_summary` и
   `net_anchor_sensitivity`.
2. **Проверка.** Напишите `review.json`: времена касаний внутри проверенных
   интервалов, априорные значения пикселя и высоты касания, а для последнего
   полёта сегмента необязательную зону приземления или `open`.
3. **Анализ и рендеринг.**

   ```bash
   uv run shuttle-replay analyze --tracks tracks.json --review review.json \
       --calibration calibration.json -o analysis.json
   uv run shuttle-replay render --video match.mp4 --analysis analysis.json -o replay.mp4
   # or both at once:
   uv run shuttle-replay run --video match.mp4 --tracks tracks.json --review review.json \
       --calibration calibration.json --out-dir out
   ```

   Несогласованные входные данные (немонотонный PTS, несмежные сегменты,
   касания вне своего сегмента или интервала, PTS, не совпадающий с видео, …)
   останавливают работу с кодом выхода 2 и сообщением; ничего не исправляется
   молча.

## Что делает каждая команда

- **`calibrate`**: гомография по ≥ 4 проверенным точкам пола плюс вертикальный
  столбец матрицы камеры по ≥ 2 приподнятым опорным точкам сетки. Отложенные
  точки пола никогда не используются для подгонки и выводятся отдельно.
  Вырожденные, дублирующиеся, коллинеарные и неконечные входные данные
  отклоняются. Гомография пола никогда не используется для точек в воздухе.
- **`analyze`**: один полёт на каждое проверенное касание, время отсчитывается
  от проверенного касания. Смены плана исключаются, и полёты никогда не
  переходят через сегменты. Каждый полёт заканчивается на следующем касании,
  в проверенной зоне приземления (это ограничение, а не измеренная
  координата) или на последнем наблюдении сегмента. Проверки пола и сетки
  отклоняют невозможные подгонки. Пропущенные детекции остаются null.
- **`render`**: сверяет каждый декодированный кадр исходника с PTS трека и
  рисует переданные рамки игроков, наблюдаемые кольца волана (зелёные),
  кольца модели (оранжевые) и вид корта сверху в раскладке 6:4. Звук
  исходника копируется потоком без перекодирования. Существующие выходные
  файлы никогда не перезаписываются.
- **`demo`**: генерирует синтетический розыгрыш и запускает весь конвейер.

## Как читать выходные данные

| Слой | Значение |
| --- | --- |
| `observed_pixel` | переданная детекция без изменений; null, если отсутствует |
| `human_review` | ваши касания, зоны приземления и точки калибровки |
| `conditional_model` | физическая модель, подогнанная к наблюдаемым пикселям при ваших априорных данных |
| `display_interpolation` | линии и маркеры, рисуемые только рендерером |

Скорости являются начальной скоростью подогнанной модели (`model_speed_km_h`,
показывается с округлением до 5 км/ч). Считайте их грубыми значениями модели,
а не измерениями.

## Ограничения

- Нет детекции волана или игроков и нет встроенных весов.
- Нет автоматического поиска касаний или уточнения временных меток касаний.
- Нет обученных карт плотной глубины, нет обученных меток ударов, нет автоматических решений IN/OUT.
- 3D-вывод условен, а не измерен. Результаты синтетического восстановления синтетические.

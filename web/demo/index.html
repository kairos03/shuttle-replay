비행 목록

항목을 누르면 사람이 검토한 접촉 시각(t0) 이후 첫 분석 프레임으로 이동합니다. 채택되지 않은 비행도 그대로 표시하며, 그 모델은 그리지 않습니다.

    이 분석에는 비행이 없습니다.

    로컬 파일 열기

    파일은 이 브라우저 안에서만 읽습니다. 업로드·네트워크 전송 없음.

    분석 시각 = 영상 재생 시각 + 오프셋. 원본의 첫 PTS가 0이 아니었거나 다시 인코딩해 시작점이 바뀐 경우에만 조정하세요.

    데이터 역할

    원본 영상
    입력 영상 그대로. 샘플은 파이프라인이 만든 합성 영상이며 실제 경기가 아닙니다.
    관측 픽셀
    제공된 2D 검출을 바꾸지 않고 표시. 영상 위에만 그립니다.
    사람 검토
    접촉 시각·높이, 착지 영역, 보정점. 비행 목록의 t0 기준입니다.
    조건부 모델
    검토 사전값 아래 중력+항력 모델을 관측 픽셀에 맞춘 결과. 측정값이 아니며 높이·초기 속도는 추정입니다. IN/OUT 판정을 하지 않습니다.

    카메라 컷, 세그먼트 없음, 검출 공백, 채택되지 않은 비행, 서로 다른 비행·세그먼트 사이에는 선을 잇지 않습니다.
